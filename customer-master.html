Bulk Add Parties

Paste one party per line (Excel column copy works). Parties already in the list are skipped. Saved as Active, PAN-only / Unregistered, State below, Credit Days 0. GSTIN, mobile and address can be filled later with Edit.

Excel Import / Export

Export downloads the full party list to Excel. Edit it, or fill new parties in the Template, then Import. Rows are matched by Party Name: a new name creates a party, an existing name updates it. Blank cells keep the saved value. Import is Admin only.

These Active parties are not in the Excel file you chose. If the new file is your full, clean party list, set them Inactive. Nothing is deleted: their old POs and ledger stay, and you can make any party Active again with Edit.

Duplicate Party Suggestions

Finds parties with the same or nearly the same name, the same GSTIN / PAN or the same mobile. Choose the party to Keep and press Merge: its POs, bills, payments, ledger and salesman move to the kept party, missing details are copied, and the other party is set Inactive (never deleted). Admin only.
